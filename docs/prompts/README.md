# Prompts

Every prompt I give Claude Code is saved here, so the repo holds the full history of how the project was built.

## Naming

`NN-short-name.md`: a two-digit running number, then a few words in kebab-case.

```
01-initial-build.md
02-mobile-nav.md
03-contact-form.md
```

## Rules

- One file per prompt, saved exactly as given.
- Numbers keep going up and are never reused, even if a prompt is abandoned.
- Claude Code saves the prompt as the first step of each task (see CLAUDE.md).
